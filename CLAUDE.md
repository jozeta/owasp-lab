# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

An **intentionally vulnerable** training lab for the OWASP Top 10 (2021), in the spirit of
WebGoat, Juice Shop and DVWA. Flask + SQLAlchemy on PostgreSQL, with an OpenLDAP container and a
vendored, deliberately unpatched ImageMagick (A06 ImageTragick). Every exercise is a real, working
vulnerability.

> The vulnerabilities are the product. Do not "fix" a vulnerable route unless asked; changes
> should keep each exercise exploitable exactly as its hints and tests describe.

## Commands

```sh
cp .env.example .env
docker compose up --build            # first build compiles ImageMagick; slow once, then cached
# app: http://127.0.0.1:5001  (seeded users: alice, bob, carol, admin)

python -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/pytest tests/ -v           # in-memory SQLite, no Docker/Postgres needed
```

`/force-reset` resets the DB and session even when the UI is broken. Production server is
gunicorn (`gunicorn.conf.py`).

## Layout

- `app/__init__.py`, `config.py`, `extensions.py`: app factory, settings, db.
- `app/core/`: auth, models, nav, badges, stats, seeding, shared views and templates.
- `app/categories/aNN_<name>/`: one package per OWASP category (A01–A10), each with
  `routes.py`, `models.py`, `seed.py`, `templates/` and any fixtures (e.g. A03 has LDAP client and
  seed, plus `*_secret.txt` flag files that exploits are meant to read).
- `static/`: lab CSS/JS and **vendored** Bootstrap, highlight.js and IBM Plex (no CDN).
- `tests/test_aNN_*.py`: one test file per exercise, proving the vulnerability works (and that
  hints render).
- `docs/superpowers/`: design specs and implementation plans.

## Adding an exercise

Each category package's `__init__.py` defines its blueprint (`aNN_bp`, registered in
`app/__init__.py`) and lists its exercises as `ExampleNav(...)` entries (id, title, difficulty
Easy/Medium/Hard, endpoint, hints; dataclasses in `app/core/nav.py`). To add one: add the route,
template and seed data in the category package, add its `ExampleNav` entry, and add a
`tests/test_aNN_<exercise>.py` that performs the exploit. Use only synthetic data, and keep the
README category summary in sync.

## Safety rules (never weaken these)

- The app binds to `127.0.0.1:5001` only; Postgres publishes no host port. Never change
  bindings to `0.0.0.0` or add public-facing deploy config.
- Container runs as non-root `appuser`.
- All data is synthetic and regenerated by "Reset lab". Never add real credentials or PII.
- The persistent "intentionally vulnerable" warning banner must stay.
- Vulnerabilities stay inside the lab's own app and containers: no exercise may reach out to
  or attack third-party systems.
