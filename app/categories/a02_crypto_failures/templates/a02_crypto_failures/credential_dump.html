This page simulates a leaked database backup — a legacy export that was never properly secured. Passwords in it are stored as unsalted MD5 hashes, a format that's been considered broken for password storage for well over a decade: no salt means two identical passwords produce identical hashes, and MD5 is fast enough that a modern GPU can try billions of guesses per second.

Impact here: anyone who can reach this page can crack every password in seconds using a public rainbow table.
