This "continue to your destination" feature redirects the browser to whatever URL is given in the next parameter, with no validation of any kind. Flask's redirect() helper sends the exact string it's given as the response's Location header -- it performs no host-checking on its own.

{% endblock %} {% block detect %}

Submit ?next=/a01/ and confirm you land back on this category's overview page. Then try an external URL instead.

{% endblock %} {% block exploitation %}

Submit ?next=https://evil.example.com/phish -- the response is a real redirect straight to that external address, no validation stops it.

Real-world impact: an attacker crafts a link like https://this-trusted-site.com/continue?next=https://evil.example.com/phish and distributes it via email or social media. Because the visible domain in the link is the trusted site's own, victims are far more likely to click it than a raw link to the attacker's domain -- landing them on a convincing phishing page after a brief, legitimate-looking bounce through a site they already trust.
