This "document center" lets you download a file by name from a shared documents folder. The name you provide is joined directly onto that folder's path with no validation of any kind — Python's os.path.join() is not a safety mechanism: if the second argument is an absolute path, it discards the first argument entirely, and a relative ../ sequence climbs out of the intended folder just as easily as it would in any other language.

{% endblock %} {% block detect %}

Fetch ?name=welcome.txt and note the legitimate content. Then try ?name=/etc/passwd — no ../ at all, just a bare absolute path.

{% endblock %} {% block exploitation %}

Two independent techniques both work here, since neither the intended folder restriction nor os.path.join()'s own behavior stop either one:

  1. Classic relative traversal: ?name=../../../../../../etc/passwd climbs out of the documents folder one directory at a time.
  2. os.path.join()'s absolute-path override: ?name=/etc/passwd — when the second argument to os.path.join() is an absolute path, Python discards the first argument entirely and returns just the absolute path, no traversal sequence required at all.

Either payload returns the real contents of /etc/passwd — a file completely outside the intended documents folder, disclosed with no access control of any kind.
