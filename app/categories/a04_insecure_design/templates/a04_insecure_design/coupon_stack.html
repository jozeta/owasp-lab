Two valid, independent coupon codes exist: WELCOME10 ($5.00 off) and SAVE20 ($10.00 off). The form has a single "code" input, implying only one code applies per order — but the server reads every submitted code value and applies a discount for each one present, instead of validating exactly one. This is different from this category's existing "unlimited coupon reuse" example, which is about resubmitting the same code repeatedly over time — this one is about submitting multiple distinct codes in a single request.

{% endblock %} {% block detect %}

Submit the form with the code field duplicated — most HTTP clients let you send the same parameter name twice in one request body. If both discounts apply at once, the server is reading a list of values instead of validating a single code.

{% endblock %} {% block exploitation %} 
curl -X POST http://127.0.0.1:5001/a04/coupon-stack -d "code=WELCOME10&code=SAVE20"

Both the $5.00 and $10.00 discounts apply in one single order — a combination the storefront never intends to offer, since each code is meant to be used on its own.
