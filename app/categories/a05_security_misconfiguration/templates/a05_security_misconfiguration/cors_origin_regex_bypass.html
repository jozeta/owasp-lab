{% extends "core/example_page_base.html" %} {% set example_title = "CORS: Origin Allowlist Regex Bypass" %} {% set example_difficulty = "Hard" %} {% block title %}{{ example_title }} — A05{% endblock %} {% block explanation %}

This "partner portal" API is meant to allow only genuine https://partner.example.com-style origins, checked with the regular expression https://.*example\.com. The pattern has no end-anchor ($), so it only requires the origin to start with https:// and contain example.com somewhere after that — it never confirms the origin actually ends at example.com.

{% endblock %} {% block detect %}

Try an origin that contains the trusted domain as a substring but isn't actually that domain — e.g. https://evilexample.com (no dot between "evil" and "example"). If it's accepted, the allowlist regex isn't properly anchored.

{% endblock %} {% block exploitation %} 
curl -s http://127.0.0.1:5001/a05/api/partner-portal -H "Origin: https://evilexample.com"

The response reflects Access-Control-Allow-Origin: https://evilexample.com with Access-Control-Allow-Credentials: true, even though evilexample.com is not a real partner domain — a regex meant to match only example.com matches anything containing that substring after the scheme, with nothing requiring the string to actually end there. An attacker who registers any domain ending in example.com as a substring (or, with a different unescaped-dot variant of this same bug, a domain like apiXexample.com where the dot in the pattern was never escaped) gains a fully credentialed cross-origin channel to this API.

{% endblock %} {% block vulnerable_code %}PARTNER_PORTAL_ORIGIN_PATTERN = re.compile(r"https://.*example\.com") origin = request.headers.get("Origin") # VULNERABLE: no end-anchor ($) -- matches "https://evilexample.com" just # as validly as "https://partner.example.com" if origin and PARTNER_PORTAL_ORIGIN_PATTERN.match(origin): resp.headers["Access-Control-Allow-Origin"] = origin resp.headers["Access-Control-Allow-Credentials"] = "true" {% endblock %} {% block secure_code %}PARTNER_PORTAL_ORIGIN_PATTERN = re.compile(r"^https://([a-z0-9-]+\.)?example\.com$") origin = request.headers.get("Origin") # Anchored at both ends, and the subdomain segment can't contain a # literal dot itself -- "evilexample.com" and "apiXexample.com" both fail if origin and PARTNER_PORTAL_ORIGIN_PATTERN.match(origin): resp.headers["Access-Control-Allow-Origin"] = origin resp.headers["Access-Control-Allow-Credentials"] = "true" {% endblock %} {% block live_example %}
