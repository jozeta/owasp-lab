This shopping cart stores its contents in a cookie, serialized with Python's pickle module and base64-encoded. Pickle has no built-in integrity protection at all — it will happily deserialize any valid pickle bytes, whether the server wrote them or an attacker crafted them from scratch.

{% endblock %} {% block detect %}

Reload this page a few times — the cart's contents persist across visits via the a08_cart cookie. Nothing about the cookie's value looks like it's been signed or checksummed; it's just base64- encoded pickle bytes, and the server never asks "did I actually issue this?"

{% endblock %} {% block exploitation %}

Run this locally to craft your own cart cookie with a tampered price — you never need to see or modify the server's real cookie, just know the expected shape: 

python3 -c "
import pickle, base64
print(base64.b64encode(pickle.dumps({'item': 'Widget', 'price': 0.01})).decode())
"

Set your a08_cart cookie to the printed value (via browser dev tools, or curl -b "a08_cart=<value>") and reload this page — the price shows 0.01, accepted with no complaint. The server never had a way to tell your crafted pickle from its own.
